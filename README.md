# ⛏️ 꿈나라 대모험

윤이와 아빠가 AI와 함께 만드는 **횡스크롤 액션 게임**.
잠옷 입은 꼬마가 곡괭이를 들고 꿈속 숲길을 달려 왕밤톨이를 물리치는 것이 목표입니다.

빌드 도구·외부 CDN·네트워크 요청이 전혀 없습니다. 순수 HTML/CSS/JS + Canvas 2D.

## 플레이

```bash
python3 -m http.server 4174 --directory dream-mine
```

브라우저에서 http://localhost:4174 접속.

| 조작 | 키 |
|---|---|
| 걷기 | `←` `→` |
| 점프 · 꼬리 활강(공중에서 꾹) | `↑` `W` |
| 공격 (연달아 누르면 3단 콤보) | `Space` `Z` `X` · 화면 클릭/탭 |
| 대시 | `Shift` · 방향 버튼 더블탭 |
| 무기 바꾸기 | `1` 칼 · `2` 방패 · `3` 도토리 |

아이패드에서는 화면 아래 버튼으로 전부 조작할 수 있습니다.
(Safari → 공유 → **홈 화면에 추가**하면 전체화면 앱처럼 열립니다.)

## 구조

```
dream-mine/
├─ index.html      마크업만 (93줄)
├─ style.css       HUD · 핫바 · 터치버튼 · 오버레이
├─ js/             ← 순서대로 읽히는 평범한 스크립트 (모듈/번들러 없음)
│  ├─ core.js      상수 · 캔버스 · 유틸 · WebAudio 효과음 합성
│  ├─ fx.js        입자 · 충격파 링 · 화면 펀치 · 떠오르는 숫자
│  ├─ player.js    무기 정의 · 공격 판정 · 플레이어 한 프레임
│  ├─ anim.js      포즈 키프레임 애니메이션 · 주인공 그리기
│  ├─ enemy.js     밤톨이 · 통통이 · 잎새
│  ├─ stage.js     스테이지 데이터 · 지형 충돌 · 카메라 · 스트리밍
│  ├─ boss.js      왕밤톨이
│  ├─ render.js    배경(시차) · 지형 · 화면 합성
│  ├─ input.js     키보드/터치 입력 · 무기 핫바
│  └─ game.js      전역 상태 · HUD · 메인 루프 · 화면 전환
└─ test/           헤드리스 회귀 테스트
```

각 파일 맨 위에 로드 순서와 의존 관계가 적혀 있습니다.
전역 상태를 그대로 공유하는 구조라 **`index.html`의 script 순서가 곧 의존 순서**입니다.

## 아이템

마리오를 참고해 네 갈래로 나눴습니다 — 모으는 것 · 회복 · 변신 · 시간제 강화.

| | 이름 | 효과 | 참고한 것 |
|---|---|---|---|
| 🌰 | 도토리 | +25점 | 코인 |
| ❤️ | 하트 | 체력 1 회복 | 1UP |
| 🍄 | 도토리버섯 | 커진다. 칼 사거리 +14. **한 대 맞으면 체력 대신 변신이 깨진다** | 슈퍼버섯 |
| ⭐ | 반짝별 | 8초간 무적 + 몸이 무지개. 닿기만 해도 적이 사라지고, 보스도 조금씩 깎인다 | 무적 스타 |
| 🍯 | 꿀단지 | 10초간 모든 공격 데미지 2배, 칼이 금빛 | 파이어플라워 |
| 🍃 | 나뭇잎 | 15초간 꼬리 활강이 훨씬 느려진다 (낙하 130 → 78px/s) | 너구리 나뭇잎 |
| 💎 | 강화 다이아몬드 | **손에 든 무기**를 한 단계 올린다 (최고 단계면 +100점) | 다이아몬드 도구 |

🍄의 "변신만 깨진다"가 이 게임에서 제일 중요한 장치입니다. 아이에게 **실수 한 번을
봐주는 안전망**이라서, 체력 5칸이 실질적으로 6칸이 되고 무엇보다 덜 억울합니다.

### 무기 강화 — 나무 → 돌 → 다이아몬드

💎를 먹으면 **그때 손에 들고 있던 무기**만 올라갑니다. 무엇을 키울지는 아이가 고릅니다.
스테이지에 💎는 4개뿐이라 (전부 올리려면 6개 필요) 자연스럽게 선택이 생깁니다.

| 무기 | 🪵 나무 | 🪨 돌 | 💎 다이아몬드 |
|---|---|---|---|
| 🗡️ 칼 | 기본 | 사거리 +9 · 넉백 +18% | 사거리 +18 · 넉백 +36% · **데미지 +1** (마무리는 3칸) |
| 🛡️ 방패 | 밀치기 1칸 | 밀치는 힘 +30% | 밀치기 2칸 · **막은 도토리를 되쏜다** |
| 🌰 도토리 | 1발 1칸 | 1발 **2칸** · 더 빠르게 | **3발 산탄** · 2칸 · **적 하나를 관통** |

세지는 방식을 무기마다 다르게 했습니다 — 칼은 힘, 방패는 되받아치기, 도토리는 숫자.
같은 "강해짐"이라도 손에 잡히는 느낌이 달라야 고르는 재미가 생깁니다.
핫바에 단계 표시(🪵🪨💎)와 테두리 색으로 지금 상태가 보입니다.

힘 아이템은 **그 힘이 필요한 구간 바로 앞**에 둡니다 — 나뭇잎은 공중 구간 앞,
꿀단지는 싸움터 앞, 별은 보스 직전. 적을 쓰러뜨리면 32% 확률로 도토리,
체력이 깎였을 땐 14% 확률로 하트를 떨어뜨립니다.

## 스테이지 편집

좌표를 손으로 고치지 않고 [Tiled](https://www.mapeditor.org/)(무료 오픈소스 레벨 에디터)로 만듭니다.

```bash
# stage/stage1.tmj 를 Tiled로 열어 편집 → 저장 → 변환
node tools/tiled-to-stage.js
```

레이어 네 개(`plats`·`blocks`·`enemies`·`items`)로 되어 있고, 적과 아이템은 점 오브젝트의
`kind` 속성으로 종류를 정합니다. 타일셋 이미지가 필요 없어서 Tiled에서 바로 열립니다.
변환기가 모르는 종류나 범위를 벗어난 값을 막아주고, 결과물 `js/stage-data.js`는
그대로 커밋하므로 **게임 실행에는 Node가 필요 없습니다**.

## 아이콘

홈 화면 아이콘(`icon.png`, 180×180)은 그림 파일을 직접 만지지 않고 코드로 생성합니다.

```bash
node tools/make-icon.js
```

외부 라이브러리 없이 픽셀을 찍고 zlib으로 PNG를 조립합니다. 4배 크기로 그린 뒤
줄여서 계단현상을 없앱니다. 모양을 바꾸려면 스크립트의 좌표만 고치면 됩니다.

## 테스트

```bash
node test/game.test.js index.html
```

캔버스·DOM·오디오를 스텁으로 막고 `requestAnimationFrame`을 직접 펌프해서
게임 루프를 결정론적으로 돌립니다. 난수는 시드 고정이라 몇 번을 돌려도 결과가 같습니다.

검사 항목: 칼 콤보 연결/리셋 · 대시 거리와 쿨타임 · 히트스톱(정지 중 월드가 실제로
멈추는지) · 적 경직 · 마무리 일격 · 애니메이션 클립 선택과 포즈 건전성 · 카메라 ·
스테이지 스트리밍 · 보스 전 과정 · **오른쪽으로 달리면 보스까지 도달하는지** ·
**보스를 실제로 쓰러뜨릴 수 있는지** · 장시간 구동 무사고.

## 게임 설계 메모

- **히트스톱** — 맞는 순간 화면을 멈춘다. 일반 0.055초, 처치 0.105초, 마무리 0.125초.
  타격감의 8할이 여기서 나온다.
- **적 경직** — 맞은 적은 0.22초(마무리는 0.38초) 멈추고, 그동안 플레이어를 다치게
  하지 않는다. 선빵을 날린 쪽이 유리해야 붙어서 싸울 수 있다.
- **관대한 조작** — 코요테 타임 0.12초, 점프 선입력 0.14초, 공격 선입력 0.2초.
  아이가 타이밍을 조금 놓쳐도 성공하게 만든다.
- **보스의 "지금!"** — 지친 구간에는 머리 위에 표시가 뜨고 데미지가 2배.
  언제 때려야 하는지 글자 없이 알 수 있어야 한다.
- 튜닝 수치는 테이블 한 곳에 모여 있다 —
  `SWORD_COMBO`([js/player.js](js/player.js)), `ANIM`([js/anim.js](js/anim.js)),
  `STAGE`([js/stage.js](js/stage.js)).
